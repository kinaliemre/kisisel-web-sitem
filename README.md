# Emre Can Kınalı — Kişisel portfolyo

İstanbul Arel Üniversitesi bilgisayar mühendisliği 3. sınıf öğrencisi için Türkçe, mobil uyumlu kişisel web sitesi. HTML, CSS ve JavaScript ile hazırlanmıştır; dış bağımlılık ve derleme gerektirmez.

## Yerel önizleme

Node.js ile `npm run dev` çalıştırın, ardından http://localhost:3000 adresini açın. Alternatif olarak `index.html` doğrudan tarayıcıda açılabilir.

`npm run check` JavaScript dosyalarının sözdizimini doğrular.

## Düzenleme

- `index.html`: Kişisel bilgiler, bölüm metinleri, proje kartları, GitHub bağlantıları.
- `style.css`: Renkler, tipografi, masaüstü ve mobil düzenler.
- `script.js`: Proje fikri pencereleri ve yıl bilgisi.
- `favicon.svg`: Sekme simgesi.

Görev takipçisi ve algoritma atölyesi tamamlanmış projeler değildir; taslakta açıkça proje fikri olarak gösterilir. İsim ve GitHub kullanıcı adı bağlı GitHub profilinden alınmıştır. İletişim bölümü GitHub profiline yönlendirir.

## GitHub Pages

Dosyalar statik barındırmaya hazırdır. Depo GitHub'a gönderildikten sonra Settings → Pages bölümünde “Deploy from a branch”, `main` ve `/ (root)` seçilerek yayınlanabilir. Göreli dosya bağlantıları hem kullanıcı hem proje sitelerini destekler. Pages yayınlama bu taslağın hazırlanması sırasında etkinleştirilmemiştir.
